# Changelog v0.2.0

## Added
* Auto-indent for delimiter pairs (`{}`, `()`, `[]` by default) when inserting newlines.
* Customizable `[indent]` section in `settings.toml` — define global `pairs` and optional per-bracket `indent_size` overrides.
* Blinking line cursor (`|`) instead of the default block cursor (`█`).
* Persistent undo/redo history — automatically saved per file and restored on reopen.
* Configurable, redefinable keybindings via `settings.toml` under `[keybindings]`.
* Custom Nerd Font folder/file-type icons in the explorer view (requires a Nerd Font installed).

## Changed
* Newline inside a delimiter pair (e.g. `{|}`) now splits it into two properly indented lines.
* A line ending in an opening delimiter (e.g. `{`) now increases indentation on the next line.
* `Ctrl+A` (select all) now correctly includes the last character of the file.
* Explorer items now render with styled, per-type foreground colors.

## Fixed
* Bracketed paste support — multi-line pastes no longer trigger recursive auto-indent ("staircasing").
* Native system clipboard integration (`Ctrl+C`/`Ctrl+V`) via PowerShell on Windows and xclip/xsel/wl-clipboard on Linux — no more trailing padding or line-number selection bugs when copying to/from external tools.
* Snippet autocomplete popup now only triggers when actively typing or backspacing, preventing it from opening and hijacking/blocking cursor navigation when scrolling or moving onto existing keywords.

## Internals
* New `src/indent.rs` module (unit-tested) for auto-indent logic, wired into `insert_newline`.
* Key event routing (`map_key_event`) now checks user keybindings before defaults.
